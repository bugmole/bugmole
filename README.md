# Valkyrie QA — Community

Ask questions, share how you're using Valkyrie, and get help from the team and other users.

**👉 [Start a discussion](https://github.com/theaiinc/valkyrie-community/discussions)**

- **Q&A** — stuck on something? Ask here.
- **Ideas** — a feature you'd like to see.
- **Show and tell** — what you've built or automated with Valkyrie.
- **Announcements** — releases and changes, posted by the team.

## Found a bug?

Use **Report a bug** from inside the Valkyrie dashboard — it attaches a screenshot, console logs and your environment automatically, and creates a tracked issue for the team. That's faster for both of you than describing it here.

## Other ways to reach us

- Docs: https://tryvalk.app/docs/
- Email: info@theaiinc.com

This repo is for discussion only — it has no code and doesn't track issues. Valkyrie itself lives in a private repository.
