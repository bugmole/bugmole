# MCP configs

Every assistant uses the same server URL, `https://api.bugmole.com/mcp`, and signs in as you. Setup for ChatGPT and Claude Desktop, which use a settings screen instead of a file, is in [Use Bugmole from your AI assistant](https://bugmole.com/docs/ai-assistants/).

| File | Assistant |
| --- | --- |
| `claude-code.sh` | Claude Code |
| `cursor-mcp.json` | Cursor (`.cursor/mcp.json`) |
| `codex-config.toml` | Codex CLI |
